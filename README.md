# Machine Learning Prediction and Interpretability of Ionic Liquid Transport Properties

Prediction of four transport properties of ionic liquids (ILs) from molecular structure (SMILES) — cation/anion self-diffusion coefficients (**D⁺**, **D⁻**), electrical conductivity (**σ**), and thermal conductivity (**λ**) — using Graph Neural Networks (GCN / GAT / GIN) and traditional ML models (MLP / Random Forest / XGBoost), followed by multi-level interpretability analysis (SHAP, ILExplainer, VNEO) and TOPSIS-based multi-objective virtual screening of 10,000 candidate ILs.

## Repository Structure

```
├── Diff_program/                    # D+ and D- prediction
├── ElectricalConductivity_program/  # σ prediction
├── ThermalConductivity_program/     # λ prediction (adds Pressure as a condition)
├── virtual_IL/                      # Virtual screening: 200 cations × 50 anions × 4 temperatures
│   ├── predict_virtual_ils.py       #   Batch property prediction with trained GIN models
│   ├── plot_screening_3d.py         #   3D TOPSIS screening plots (per temperature)
│   ├── plot_composition.py          #   Anion/cation composition of top-50 candidates
│   └── topsis_top50_screening.csv   #   Screening results (Damb, σ, λ, TOPSIS score)
└── requirements.txt                 # Shared dependencies
```

The three property programs share the same architecture:

```
├── configs/                  # YAML configuration files
├── data/
│   ├── raw/                  # Raw CSV data (SMILES, conditions, targets)
│   └── processed/            # Preprocessed features (graphs, fingerprints, etc.)
├── results/
│   ├── checkpoints/          # Saved model weights (.pth)
│   ├── figures/              # Plots (predictions, SHAP, error distributions)
│   └── fragment_explain/     # Fragment & atom importance (ILExplainer / VNEO)
├── scripts/                  # Entry-point scripts
└── src/
    ├── data_processing/      # SMILES → graphs / fingerprints / descriptors
    ├── datasets/             # PyTorch Dataset classes
    ├── models/               # GCN, GAT, GIN, MLP, RandomForest, XGBoost
    ├── training/             # Training loops
    ├── evaluation/           # Metrics, visualization, SHAP, GNNExplainer
    └── utils/                # Data loading, splitting
```

## Installation

**1. Install PyTorch (CUDA 13.2):**

```bash
pip3 install torch==2.12.0 torchvision==0.27.0 --index-url https://download.pytorch.org/whl/cu132
```

**2. Install remaining dependencies (from the repository root):**

```bash
pip install -r requirements.txt
```

## Usage

Each property program is self-contained. Run scripts from within the corresponding program directory.

### 1. Preprocessing

```bash
cd Diff_program   # or ElectricalConductivity_program / ThermalConductivity_program

# Molecular graphs (for GNN models)
python scripts/preprocess_graph_data.py

# Fragment-annotated graphs (for explainability)
python scripts/preprocess_fragment_data.py
```

Fingerprints, group counts, and molecular descriptors are generated by running the corresponding modules directly (e.g., `python -m src.data_processing.smiles2fingerprint`).

### 2. Training & Evaluation

```bash
# GNN models (GCN / GAT / GIN)
python scripts/run_gnn.py configs/gcn.yaml
python scripts/run_gnn.py configs/gat.yaml
python scripts/run_gnn.py configs/gin.yaml

# ML models (MLP / RandomForest / XGBoost)
python scripts/run_ml.py configs/mlp_fp.yaml
python scripts/run_ml.py configs/rf_descriptor.yaml
python scripts/run_ml.py configs/xgboost_gc.yaml
```

### 3. Explainability

```bash
# Fragment importance across all samples (ILExplainer / VNEO)
python scripts/explain_batch.py

# Single sample explanation (atom importance heatmap)
python scripts/explain_single.py
```

### 4. Virtual Screening

Uses the trained GIN checkpoints from the three property programs:

```bash
cd virtual_IL
python predict_virtual_ils.py      # predicts D+, D-, σ, λ for 10,000 candidate ILs
python plot_screening_3d.py        # 3D TOPSIS screening figures (top-50 highlighted)
python plot_composition.py         # anion/cation composition of top-50 candidates
```

## Configuration

All training parameters are specified in YAML config files under each program's `configs/`. Key fields:

| Field | Description |
|---|---|
| `model.name` | Model type: `gcn`, `gat`, `gin`, `mlp`, `random_forest`, `xgboost` |
| `model.params` | Architecture / hyperparameter search space |
| `data.feature_type` | Feature type: `graph`, `fingerprint`, `group_count`, `descriptor` |
| `data.target` | Prediction target: `D+` / `D-` (Diff_program), `sigma` (ElectricalConductivity_program), `lambda` (ThermalConductivity_program) |
| `training.epochs` | Number of training epochs (deep learning models) |
| `training.lr` | Learning rate |
| `training.batch_size` | Batch size |
| `training.test_size` | Test set ratio (default 0.2) |
